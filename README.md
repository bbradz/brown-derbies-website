# Brown Derbies Website

This is a documented, shared version of the Brown Derbies website (live at [brownderbies.com](http://brownderbies.com)), meant to be picked up by other derbies who want to iterate on and improve the site.

For AWS account access and deploy credentials for brownderbies.com (S3 bucket setup, CLI configuration, and push/pull commands), see the **[Website Technicals](https://docs.google.com/document/d/1bSh2DBxQs-qfQ5u1b9ASpl7plscHWqDDZn0ogc7ebEI/edit?tab=t.0)** doc on the Derby Google Drive.

> This doc contains live AWS account credentials — do not copy its contents anywhere public (this repo, issues, chats, etc.). Access is restricted to trusted derby members who need to deploy the site.
