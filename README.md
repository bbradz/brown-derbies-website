# Brown Derbies Website

This is a documented, shared version of the Brown Derbies website (live at [brownderbies.com](https://brownderbies.com)), meant to be picked up by other derbies who want to iterate on and improve the site.

For technical details — hosting setup, deploy process, and site structure — see the **[Website Technicals](https://docs.google.com/document/d/1bSh2DBxQs-qfQ5u1b9ASpl7plscHWqDDZn0ogc7ebEI/edit?tab=t.0)** doc on the Derby Google Drive.
